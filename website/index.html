ToDoRabbit
Features Self-hosting GitHub

A simple and elegant todo list

Capture tasks in seconds, check them off, and archive what you are done with. Runs on your own server with a single command.

Get started Read the docs

Everything you need, nothing you do not

Quick capture

Add a title and an optional description. Your list updates instantly.

Filter and archive

Show open or completed tasks, and archive finished work to keep your list tidy.

Simple REST API

Every action in the app is available over a documented JSON API.

Self-host in one command

ToDoRabbit ships with Docker Compose. Clone the repository and start both services:

git clone https://github.com/coderabbitai/ToDoRabbit.git
cd ToDoRabbit
make up

Open http://localhost:3000 and add your first task.
