ToDoRabbit ships with Docker Compose. Clone the repository and start both services:

git clone https://github.com/coderabbitai/ToDoRabbit.git
cd ToDoRabbit
make up

Open http://localhost:3000 and add your first task.

Frequently asked questions

Do I need to run a database server?

No. ToDoRabbit stores your tasks in a SQLite file, so there is nothing else to install or maintain.

How do I start the app after cloning?

Run make start from the project root. Docker Compose builds both services and the app is available on port 3000.

Can I use a different database?

Yes. Set the DATABASE_URL environment variable to any SQLAlchemy async database URL.
